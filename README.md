# Data Analytics Portfolio

A collection of project work exploring retail sales, customer behavior, data quality, inventory, and reporting. The portfolio demonstrates practical use of SQL, Python, and Power BI, with each weekly project documenting its purpose, approach, evidence, and limitations.

## About

Hi, I’m Katrina — Data Analyst in Progress
I’m transitioning into IT with a focus on data analysis, reporting automation, and business intelligence.
My work combines SQL, Python, and Power BI to turn raw data into clear insights and decision‑ready dashboards.

## What I Do
SQL — data extraction, cleaning, joins, aggregations, window functions

Python (pandas) — data wrangling, pipelines, automated reporting

Power BI / Plotly — interactive dashboards, KPI design, storytelling

Data Storytelling — transforming analysis into clear business recommendations

## Responsible data and AI use

Raw transaction files, spreadsheets, local credentials, and generated outputs are excluded from version control. The repository `.gitignore` helps keep local data and secrets out; never commit passwords, API keys, or personal customer information. Each project README describes any AI assistance used for that documentation.
