# Week 5 | Sales and Customer Reporting

## Business Problem

Retail stakeholders need a concise view of revenue, customer scale, order value, and channel performance. These screenshots preserve visual evidence of a Power BI report created for that purpose.

## Approach

Review the report visuals for overall KPIs, channel revenue, and customer acquisition by channel. The report source file and underlying data are not included in this folder.

## Key Findings

- The KPI cards display approximately **3K customers** and **2.90M total revenue**.
- The overview reports an average order value of approximately **1.14K**.
- The channel chart labels physical-store revenue at approximately **1.89M** and online revenue at **1.00M**.
- These values are rounded labels transcribed from the screenshots; the underlying model is not available here for independent validation.

## Lessons Learned and Challenges

The screenshots make the headline KPIs easy to communicate, but without the report file, measures, filters, and source data cannot be inspected or refreshed. A reproducible handoff should include a sanitized report file and definitions for each metric.
